# Cadmus 🏛️

**Cadmus** is a lightweight, struct-driven code generator for Go CLI applications. It is designed to eliminate most boilerplate by using Go's own type system and struct tags as the source of truth.

> "Sow the teeth of the serpent, and watch your CLI commands rise."

## Why Cadmus?
- **Declarative**: Define your CLI structure in plain Go structs.
- **Zero Boilerplate**: No more endless `cmd.AddCommand()` chains.
- **Self-Bootstrapping**: Cadmus is built using Cadmus.

## The Journey to Thebe
Cadmus is the CLI engine for **Thebe**, a Go-based Linux `init` library.
